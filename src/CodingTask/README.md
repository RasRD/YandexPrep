Реализуй на C# сервис оформления заказа и напиши xUnit-тесты. Время — 60 минут.

**Дано:**

- Каталог товаров: идентификатор, цена и остаток. Начальные данные корректны, цены фиксированы.
- Клиент: имя и персональная скидка в процентах.
- Корзина: список пар «идентификатор товара, количество». Товары могут повторяться.

**Требования:**

1. Корзина непустая, количество в каждой строке положительное, скидка — от 0 до 100 включительно. `null` вместо клиента, корзины или её строки недопустим.
2. Количества повторяющихся товаров суммируются.
3. Цены берутся из каталога. Скидка применяется ко всей сумме. Денежные расчёты выполняются в `decimal`; итог округляется один раз до двух знаков с `MidpointRounding.AwayFromZero`.
4. При успехе списываются остатки и возвращаются имя клиента и итоговая сумма.
5. При некорректных данных, неизвестном товаре или недостаточном остатке возвращается соответствующая ошибка. **Остатки всех товаров при этом остаются неизменными.**
6. Текущие остатки можно получить через публичный API.

Модели, интерфейсы, способ представления ошибок и набор тестов выбери самостоятельно.

Все данные хранятся в памяти. Вызовы последовательные, остатки изменяет только сервис. Переполнение чисел исключено условиями. Оплата, история заказов и многопоточность не требуются.

**Пример:** A стоит 100, остаток 5; B стоит 50, остаток 2. Корзина: A × 1, B × 1, A × 2. Скидка 10%. Результат: сумма **315**, остатки **A = 2, B = 1**.
